API reference

The whole public surface is one factory and four methods on the client it returns.

quartz(options)

Creates a client and its cache. Most applications create exactly one and export it.

client.query()

Returns the entry for a key, creating and fetching it if needed. The returned object exposes subscribe(), refetch() and a readonly state.

Arguments
Argument Type Description
key string or null Cache identity. A null key stays in the loading state and sends no request.
fetcher function Returns a promise. Receives an AbortSignal as its only argument.
options object Per query overrides for any of the client options below.

client.invalidate()

Marks one key, or every key matching a predicate, as stale. Watched entries refetch immediately and unwatched ones refetch the next time they are read.

Options

Options
Option Type Default Description
ttl number 30000 Milliseconds an entry stays fresh after it resolves.
gcTime number 300000 Milliseconds an unwatched entry is kept before it is dropped.
retry number 2 Retries after a failed request, with exponential backoff.
refetchOnFocus boolean true Revalidate stale entries when the tab regains focus.
refetchOnReconnect boolean true Revalidate stale entries when the browser comes back online.
