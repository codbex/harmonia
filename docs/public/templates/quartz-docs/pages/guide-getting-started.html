Getting started

Install the package, create a client, and read your first cached value. The whole setup is four lines, and nothing else has to change about how you fetch.

Prerequisites
Quartz needs fetch and AbortController. Every browser released since 2019 has both, and on the server it needs Node 18 or newer.

Installation

Quartz ships as an ES module with no build step and no peer dependencies.

Your first query

Create one client for the application and keep it in a module. The client owns the cache, so everything that shares a client shares its entries. The second argument to client.query() is a plain function that returns a promise, which means any HTTP library works.

The subscriber runs immediately with whatever the cache holds, then again for every state change. On a cold cache that means one call with status: 'loading' followed by one with the data. On a warm cache the first call already has the data.

Devtools

The devtools panel ships in the same package and is a single import. It lists every key in the cache with its status, its age, and whether a request is in flight, and it can force a refetch from the panel.

The panel is tree shaken out of production builds as long as the import stays behind a development guard.
